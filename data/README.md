# Dataset Information

This project uses the **Bank Customer Segmentation** dataset from Kaggle.

- **Kaggle Source**: [shivamb/bank-customer-segmentation](https://www.kaggle.com/datasets/shivamb/bank-customer-segmentation)
- **File Name**: `bank_transactions.csv`
- **File Size**: ~67.5 MB (1,048,567 transactions)
- **Time Window**: August 2016 – October 2016

## How to Download

1. Visit the Kaggle dataset page:
   https://www.kaggle.com/datasets/shivamb/bank-customer-segmentation
2. Click on **Download** to get `archive.zip`.
3. Extract `bank_transactions.csv` and place it inside this `data/` folder:
   ```text
   bank-segmentation-sql/data/bank_transactions.csv
   ```
4. Verify the row count matches 1,048,567 rows (excluding header).
